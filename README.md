# Wireshark Network Traffic Analysis Lab (Kali Linux)



## Objective

The purpose of this lab was to capture and analyze live network traffic using Wireshark in a virtualized environment to observe protocol behavior.



## Tools Used

- Kali Linux Virtual Machine

- Wireshark

- Terminal Command Line

- Firefox Web Browser



## Methodology



Live network traffic was generated and captured using Wireshark while performing the following actions:



- ICMP Traffic generated using:

&nbsp; ping 8.8.8.8



- DNS Traffic generated using:

&nbsp; nslookup example.com



- HTTP Traffic generated by browsing to:

&nbsp; http://neverssl.com



Display filters were applied within Wireshark to isolate specific protocol traffic for analysis.



## Analysis



### ICMP Traffic

ICMP echo requests and replies were captured to confirm communication between the Kali Linux host and an external server.



### DNS Traffic

DNS query and response packets were captured to observe domain name resolution into IP addresses.



### HTTP Traffic

Unencrypted HTTP traffic was captured while browsing to a test website, allowing inspection of packet-level web communication.



## Conclusion

This lab demonstrated the ability to capture and analyze ICMP, DNS, and HTTP network traffic using Wireshark. Packet-level traffic analysis is essential for monitoring network behavior and identifying potential security events in real-world environments.
